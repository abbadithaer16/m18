## Installed with a CLI: UI UX Pro Max

These seven folders are generated by the official installer rather than copied
by hand. Update them only with the same CLI (project scope, never `--global`),
then refresh this record:

```bash
npx -y ui-ux-pro-max-cli@<version> init --ai claude --force
```

| Item | Value |
|---|---|
| Upstream | [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) |
| npm package | `ui-ux-pro-max-cli@2.15.0` (command `uipro`) |
| Package integrity | `sha512-D0J/C40xrzzi5si6ZLtRGbEE5v3QjL7d4wJNnasmP3yfDSrGiuqVCdwQiqCNnIkbqOuVoA/uonR2o1WKXh3urw==` |
| Upstream commit | `a38d04c3d5c298c851dbe5e6ee1965ee3de42cb5` (tag `v2.15.0`, the package's `gitHead`) |
| Command run | `npx -y ui-ux-pro-max-cli@2.15.0 init --ai claude` (project scope) |
| Requires | Python 3 for `ui-ux-pro-max/scripts/search.py` (standard library only, no network) |
| Licence | MIT (Next Level Builder); `ui-styling` ships its own Apache-2.0 `LICENSE.txt` |

| Folder | Role here |
|---|---|
| `ui-ux-pro-max` | Main skill: `SKILL.md`, `scripts/` (search engine), `data/` (CSV datasets, stacks) |
| `design-system`, `brand`, `design`, `banner-design`, `slides`, `ui-styling` | Companion skills the CLI installs alongside it. `ui-ux-pro-max` does not depend on them |

The README documents `uipro init --dry-run`, but the 2.15.0 CLI rejects it, so
the install was previewed by running it in a throwaway checkout first. The
package ships no root `LICENSE`; the repository's MIT `LICENSE` at the tag above
was added as `LICENSE` to each folder that had none. Generated files are
otherwise unmodified.

## Licence notices

The emilkowalski, greensock and CloudAI-X repositories keep their MIT licence
only at the repository root. That root `LICENSE` file is copied verbatim into
each of their skill folders here as `LICENSE`, so the notice travels with every
copy. The two anthropics/skills skills ship their own `LICENSE.txt`, copied as is.
